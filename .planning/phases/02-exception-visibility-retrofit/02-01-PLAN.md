    Required behavior:
    - `outcomes(path)` parses the XML, builds `test_id = f"{classname}::{name}"` per `<testcase>`, and classifies as `'fail'` if a `<failure>` child exists, `'error'` if `<error>`, `'skip'` if `<skipped>`, else `'pass'`. Never read `<system-out>`, `<system-err>`, or `<properties>` — per Pitfall 5, captured log text must be ignored entirely, since the `.info`/`print()` → `.exception()` conversion legitimately changes that text.
    - CHANGED = every test_id in `before` whose after-outcome differs from its before-outcome.
    - DISAPPEARED = every test_id in `before` absent from `after` (a test that stopped being collected is a regression).
    - ADDED = every test_id in `after` absent from `before` — report these informationally with their outcomes, but they must NOT cause a nonzero exit.
    - CLI: `python junit-outcome-diff.py <before.xml> <after.xml>`. Print the counts of each category. Exit 0 only when CHANGED and DISAPPEARED are both empty; exit 1 otherwise, printing each offending test_id with its `before -> after` outcome pair.
    - On success print the literal line `IDENTICAL pass/fail/skip status before and after`.

    Do not import pytest or any third-party package — `xml.etree.ElementTree`, `sys`, and `pathlib` only, so the script runs on any interpreter.
