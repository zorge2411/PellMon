<objective>
Make the daemon fail loudly and understandably when its data folder is unusable, and stop it from
silently relocating persistent data to `/tmp`.

Purpose: the whole point of Phase 7 is that data survives; a misconfigured mount that quietly
writes to a temporary folder loses data on every restart (D-07). The settings database also holds
the future MQTT password, so its mode matters (D-09).
Output: `check_data_dirs()` in `pellmonsrv.py`, two fixed fallbacks, a 0600 settings DB, and unit
tests.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| host filesystem → daemon process (uid 999) | Bind-mounted paths may be missing, root-owned or read-only |
| settings DB file → other host users | The file will hold the MQTT password (Phase 6, D-09) |
| environment → daemon behaviour | `PELLMON_REQUIRE_DATADIR` selects fail-hard vs warn |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-08 | Information Disclosure | `pellmon_settings.db` readable by other users on the host/Pi | mitigate | `os.chmod(dbfile, 0o600)` in `Keyval_storage.__init__` (Task 3) |
| T-07-09 | Information Disclosure | settings silently written to world-readable `/tmp` | mitigate | Settings path derived from `conf.db`; `/tmp` fallback no longer reachable through the `nvdb` AttributeError (Task 2) |
| T-07-10 | Denial of Service / data loss | daemon runs "successfully" with an unwritable RRD, losing all history | mitigate | `check_data_dirs()` exits 1 with a path-naming message when `PELLMON_REQUIRE_DATADIR=1` (set for `pellmonsrv` in compose, plan 07-01) |
| T-07-11 | Tampering | attacker-controlled `PELLMON_REQUIRE_DATADIR` disabling the guard | accept | Setting container env requires control of the compose file/host; without the variable the daemon still warns loudly on stderr and in the log |
| T-07-12 | Information Disclosure | error message leaking sensitive content | accept | The message contains only directory paths and the uid, which the operator already knows |
| T-07-SC | Tampering | npm/pip/cargo installs | accept | No package installs in this plan |
</threat_model>
