## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-24 | Spoofing | all routes | mitigate | @require() on index/save/test/status (existing PBKDF2 login) |

| T-06-26 | Information disclosure | password | mitigate | Never rendered, never in status JSON, never logged; blank keeps; sentinel tests on ctx and caplog |

| T-06-27b | Spoofing (TLS downgrade) | tls_verify handling | mitigate | Missing tls_verify only means "off" with TLS on and the marker submitted; otherwise the daemon keeps the stored value; controller tests for TLS-off save and TLS enabled from a TLS-off page |

| T-06-29 | Tampering (reflected content) | index saved param | mitigate | saved maps to fixed constants; unknown values ignored, never echoed |
