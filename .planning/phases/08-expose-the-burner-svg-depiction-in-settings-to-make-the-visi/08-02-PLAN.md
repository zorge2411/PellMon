    def _check_same_origin():
        """True only if the Origin (or Referer) header names the same host as the request Host header"""
        headers = cherrypy.request.headers
        origin = headers.get('Origin') or headers.get('Referer')
        if not origin:
            return False
        try:
            netloc = urllib.parse.urlparse(origin).netloc
        except ValueError:
            return False
        return bool(netloc) and netloc == headers.get('Host')

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser -> CherryPy (`/settings/`, `/settings/save`) | Fully untrusted: form field `image`, request method, and Origin/Referer/Host headers are all attacker-controlled. |
| web process -> daemon (D-Bus) | The web tier is the first of the two whitelist tiers; the daemon re-validates (plan 08-01). |
| stored setting -> Mako template | A value that reached storage is echoed back into HTML. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-06 | Spoofing / Tampering | `Settings.save` | mitigate | `check_same_origin()` fail-closed (missing Origin AND Referer is a rejection) before any state change, mirroring `Pellmonconf.save`; 403 status and a `logger.warning` on rejection (D-07). |
| T-08-07 | Elevation of privilege | `Settings.index`, `Settings.save` | mitigate | `@require()` on both handlers puts them behind the existing `cherrypy.tools.auth` before-handler, the same gate as `getparam`/`setparam` (D-07). Asserted in tests via `_cp_config`. |
| T-08-08 | Information disclosure | `image` parameter | mitigate | `is_allowed()` strict membership against `SYSTEM_IMAGES`; the module never joins, normalizes or realpaths a caller-supplied filename, so `../`, absolute paths and NUL bytes cannot reach `serve_file` (D-02). |
| T-08-09 | Information disclosure | `effective_image` | mitigate | Re-checks membership AND `os.path.isfile` on read, so a value that somehow reached storage out-of-band still cannot select an arbitrary file; falls back to the config path. |
| T-08-10 | Tampering (XSS) | message + `current` rendered into `settings.html` | mitigate | Messages come only from the fixed UI-SPEC copy table (never echo the submitted value); `current` and gallery entries are whitelist members only. Template-side `| h` escaping is enforced in plan 08-03. |
| T-08-11 | Denial of service | `get_setting` per page render | accept | Single local D-Bus call already wrapped in `try/except`; a hung/absent daemon degrades to the config image. Same exposure as the existing `getFullDB` call on the main page. |
| T-08-12 | Repudiation | silent rejections | mitigate | Every rejection path logs `logger.warning` via the shared `pellMon` logger with origin/host or the rejected value repr. |
| T-08-SC | Tampering | package installs | accept | No package-manager installs in this phase; no change to `requirements.txt`. |
</threat_model>
