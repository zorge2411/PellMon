## Layout and Interaction Contract

**Navigation (D-01).** Add `<li><a href="${webroot}/settings/">Settings</a></li>` in the left `nav navbar-nav` list of `layout.html`, immediately after "View log". Mark `class="active"` when on the settings page.

**Page structure.** `container` > `h1` "Settings" > one `panel panel-default` per section. Phase 8 renders one panel, heading "System image". Phase 6 appends further panels below; do not hard-code a single-section assumption (each section is a self-contained `<section>` with its own form and Save button).

**Gallery (D-03).** Bootstrap grid: `col-xs-12 col-sm-6 col-md-4` per tile (1 column mobile, 2 tablet, 3 desktop), six tiles from the whitelist (only files present in `media/img/`). Each tile is a `<label>` wrapping a visually-hidden-but-focusable `<input type="radio" name="image" value="{file}">`, an `<img src="${webroot}/media/img/{file}" alt="{human name}">` with `max-height: 160px; width: 100%; object-fit: contain`, and a 12px caption with the human name. Use `<img>`, not `<object>` (no script execution).

**States.**
- Default tile: white background, 1px `#ddd` border, 16px padding.
- Hover: border `#adadad`, cursor pointer.
- Focus (keyboard via radio): 2px `#337ab7` outline with 2px offset (never removed).
- Selected (checked, pending save): 2px `#337ab7` border plus `glyphicon-ok` marker top-right.
- Current (saved value): caption suffix badge `label label-default` reading "Current". Current and selected may differ before Save.
- Save button disabled until selection differs from Current.
- Saving: button text "Saving..." and disabled; no spinner library.
- Success: `alert alert-success` above the gallery; role="status".
- Error: `alert alert-danger`; role="alert".

**Submit (D-04, D-07).** Standard `<form method="post" action="${webroot}/settings/save">`; works without JS. Progressive enhancement: JS may POST via fetch and show inline alert; either path shows the new image on next main-page load, no restart. Message text is escaped (`${msg | h}`).

**Effective-source hint.** Below the gallery, 12px helper text: "Shown on the main page. Your choice here overrides the `system_image` setting in webinterface.conf."

**Accessibility.** Radios grouped in `<fieldset>` with `<legend>` "System image"; each image has a meaningful `alt`; selected state is not conveyed by color alone (check glyph plus thicker border); contrast of text on `#fff` meets 4.5:1.

**Human names (map from filename).** system.svg = "Standard"; system_nbe.svg = "NBE"; system_nbe_2w.svg = "NBE, 2-way valve"; system_nbe_3w.svg = "NBE, 3-way valve"; system_nbe_v7.svg = "NBE V7"; system_matene.svg = "Matene". Executor: confirm the wording against each SVG and the Choices comment in `webinterface.conf.in`; keep names in the same dbus-free module as the whitelist.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Page title | Settings |
| Section heading | System image |
| Section intro | Choose the burner diagram shown on the main page. |
| Primary CTA | Save image |
| Current marker | Current |
| Success | System image saved. Reload the main page to see it. |
| Empty state heading | No system images available |
| Empty state body | No system image files were found on the server. Check the PellMon installation, or set `system_image` in webinterface.conf. |
| Error state (rejected / cross-origin / not logged in) | Could not save the image. Sign in again and retry. |
| Error state (unknown image) | That image is not available. Pick one from the list and retry. |
| Error state (daemon down) | Cannot save right now because the PellMon server is not running. The main page keeps its current image. Start the server and retry. |
| Auth not configured hint | Saving is disabled until web login credentials are configured. |
| Destructive confirmation | none: this phase has no destructive actions (a save is reversible by choosing another image) |
