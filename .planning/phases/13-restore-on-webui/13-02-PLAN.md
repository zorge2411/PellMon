<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| archive content -> rrdtool | rrd.xml from the NAS is parsed by the rrdtool binary |
| archive content -> sqlite | pellmon_settings.db from the NAS becomes the live settings DB |
| restore worker <-> Poller/copy_db | concurrent writers of the same files |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-13-07 | Denial of Service | build_rrd | mitigate | rrdtool restore into a staged file with timeout=RRD_RESTORE_TIMEOUT; live data untouched until all checks pass |
| T-13-08 | Tampering | restore_archive | mitigate | layout and future-clock checks prevent a restored RRD that breaks the Poller forever (D-07 5-6) |
| T-13-09 | Tampering | swap_in | mitigate | all locks held, os.replace on the same filesystem, .pre-restore copies, rollback on partial failure (D-09, D-11) |
| T-13-10 | Information Disclosure | .pre-restore / staged files / result file | mitigate | 0600 modes, O_EXCL|O_NOFOLLOW creation, staging 0700 removed in finally |
| T-13-11 | Tampering | read_result | mitigate | O_NOFOLLOW, size cap, field sanitisation (reason must be in REASONS, name must match NAME_RE) |
| T-13-12 | Tampering | archive settings DB | accept | an archive planted on the NAS can carry attacker settings; restore requires an authenticated human who sees archive time and machine (Phase 12 D-09, documented); web credentials live in pellmon.conf, not restored |
</threat_model>
