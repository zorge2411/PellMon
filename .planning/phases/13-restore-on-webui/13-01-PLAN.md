<objective>
Add the archive inspection and safe-extraction half of the restore engine to `src/Pellmonsrv/backup_core.py`:
fixed restore reasons, server-side archive name allow-listing, a full read-through validation pass, a cheap
manifest preview, a validated member-by-member extractor in parity with `tools/pellmon_backup.py`, SQLite
verification, staging-folder management and the free-space pre-check.

Purpose: `tools/` is not in the Docker image, so the daemon needs its own copy of the tool's hardened extractor
(D-04). Everything here is pure stdlib, no D-Bus, injected paths, so it is unit-testable in the dev container.
Output: new functions/constants in backup_core.py plus `tests/Pellmonsrv/test_backup_restore.py` (Wave 0 file
for the phase; plan 13-02 appends to it).
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| NAS/USB folder -> daemon | Archive files on the backup mount are untrusted input (anyone with write access to the share can plant one) |
| web/D-Bus caller -> daemon | Archive name is client-supplied |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-13-01 | Tampering | validate_archive_name | mitigate | NAME_RE fullmatch + must appear in list_archives + lstat S_ISREG; path built with os.path.join server-side (D-03) |
| T-13-02 | Tampering | safe_extract | mitigate | member rules: no abs/.., regular files/dirs only, realpath containment, O_EXCL|O_NOFOLLOW, mode masked to 0o755|0o600, parity test with the tool (D-04) |
| T-13-03 | Denial of Service | check_archive / safe_extract | mitigate | MAX_EXTRACT_BYTES 4 GiB running total, MANIFEST_MAX_BYTES 64 KiB, free-space pre-check (D-06) |
| T-13-04 | Information Disclosure | preview_archive | mitigate | MANIFEST_FIELDS whitelist (no rrd_path/config_dir), values truncated; config/ never extracted to scratch |
| T-13-05 | Tampering | open_archive | mitigate | O_NOFOLLOW open + fstat S_ISREG (symlink swap between listing and open) |
| T-13-06 | Tampering | staging dir | mitigate | 0700 dir inside the data dir, symlinked .restore-tmp unlinked not followed |
</threat_model>
