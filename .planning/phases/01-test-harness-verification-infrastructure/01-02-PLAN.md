<interfaces>
Source-of-truth signatures and behaviors, read directly from the codebase by the planner. Use these — do not go exploring:

From `src/Pellmonsrv/database.py` (`Keyval_storage`, lines 147-203):
- `Keyval_storage(dbfile)` — connects to `dbfile`, runs `SELECT value from keyval`; on `sqlite3.OperationalError` runs `CREATE TABLE keyval (id TEXT PRIMARY KEY, value TEXT, confvalue TEXT NOT NULL DEFAULT '-')`. Commits and closes.
- `readval(item)` — returns the stored value string. On ANY `Exception` it does `print(e); return 'error'`. It does NOT raise. A missing key therefore returns the literal string `'error'`.
- `writeval(item, value=None, confval=None)` — coerces non-`str` `value`/`confval` via `str()`. With `confval is None` it does an `INSERT OR REPLACE` preserving the existing `confvalue`. With `confval` set it compares against the stored `confvalue` and upserts `(item, confval, confval)` when they differ; a nested bare `except:` falls through to the same upsert when the row does not exist yet.

From `src/Pellmonweb/auth.py` (`AuthController`, lines 119-177) and module-level `SESSION_KEY`:
- `AuthController(credentials, lookup)` — plain attribute assignment, no CherryPy machinery needed to construct. `credentials` is membership-tested as `(username, password) in self.credentials`, so a list of 2-tuples works.
- `check_credentials(username, password)` — returns `None` on success, returns the exact string `"Incorrect username or password."` on failure. The failure branch calls `cherrypy.log(...)` referencing `cherrypy.request.headers["Remote-Addr"]`.
- `login(username=None, password=None, from_page='/')` — on success sets `cherrypy.session[SESSION_KEY]` and `cherrypy.request.login` to the username, calls `on_login()`, then `raise cherrypy.HTTPRedirect(from_page)`. On credential failure it returns `self.get_loginform(...)`, which calls `self.lookup.get_template("login.html")`.
- `logout(from_page=cherrypy.request.script_name)` — reads `cherrypy.session`, sets `sess[SESSION_KEY] = None`, and raises `cherrypy.HTTPRedirect`.

From `tests/conftest.py` (created by plan 01-01): fixtures `cherrypy_request_ctx` (patches `cherrypy.request` MagicMock with `headers={"Remote-Addr": "127.0.0.1"}` and `script_name=""`, `cherrypy.session` as a plain dict, and `cherrypy.log`), plus `loop_serial` and `mocked_udp_socket` (not needed here).
