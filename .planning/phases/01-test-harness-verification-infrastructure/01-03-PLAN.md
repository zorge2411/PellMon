**Layer 1 — parametrized per-plugin import.** Build the parametrize argument list by mapping each discovered module name to `pytest.param(name)`, except names in `KNOWN_BROKEN_MODULES`, which become `pytest.param(name, marks=pytest.mark.known_broken)`. The test body calls `importlib.import_module("Pellmonsrv.plugins." + name)`.

Inside the test, catch `ModuleNotFoundError as exc` and branch on `exc.name`:
- if `exc.name` is in `PLATFORM_UNAVAILABLE` -> `pytest.skip("<name> requires <exc.name>, unavailable on this platform (Linux/Pi-only); covered on the Linux CI runner")`
- otherwise -> `raise` (let it FAIL loudly). Do NOT use a bare `except` and do NOT blanket-skip on `ModuleNotFoundError` — that would hide exactly the defects this check exists to surface.
Any other exception type propagates untouched.

**Layer 2 — deferred-import probe.** Write `test_nbecom_deferred_protocol_import()`, marked `@pytest.mark.known_broken`, that calls `importlib.import_module("Pellmonsrv.plugins.nbecom.nbeprotocol.protocol")` directly, with no skip handling. Its docstring must state: nbecom passes Layer 1 because `from nbeprotocol.protocol import Proxy` is deferred inside `nbecomplugin.activate()` (`plugins/nbecom/__init__.py:38`), so this probe is what actually surfaces IMPORT-02; expected to FAIL until Phase 3.

**Anti-silencing guard.** Write `test_skip_allowlist_cannot_hide_migration_defects()` asserting that `PLATFORM_UNAVAILABLE` is disjoint from `{"protocol", "frames", "Scotteprotocol", "nbeprotocol", "datamap", "menus"}`. This is a tripwire: if a future contributor tries to quiet the red baseline by widening the allowlist, this test fails.

**Core-module parity.** Write `test_core_modules_import()` parametrized over the four modules the legacy root script covers — `Pellmonsrv.pellmonsrv`, `Pellmonsrv.database`, `Pellmonweb.pellmonweb`, `Pellmonweb.pellmonconf` — with the same `PLATFORM_UNAVAILABLE` skip branch (on Windows `Pellmonsrv.pellmonsrv` skips on `grp`).
