## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| human → Docker Hub account | A long-lived Read & Write credential is minted |
| human → GitHub secret store | That credential is transferred into CI |
| Docker Hub → end users | Published images are pulled and run on Raspberry Pi hardware |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-11 | Information Disclosure | Docker Hub PAT during manual setup | mitigate | Task 2 instructs the human never to paste the token into chat, a file, a commit or `.env`; Task 3 step 6 requires scanning the full job log for `dckr_pat_` and the token prefix with zero hits; Task 1 adds a repo-wide `dckr_pat_` negative assertion |
