Security
Security

Encrypts the connection to the broker. Enter the TLS port, usually 8883.

Checks that the broker's certificate is valid and matches the host name. Client certificates and custom CAs are not supported yet.${'' if s['tls'] else ' Turn on TLS to change this.'}

Certificate verification is off. The connection is encrypted, but PellMon does not check who the broker is.

Behaviour
Behaviour

Lets Home Assistant change burner settings (temperature setpoints, power limits, cleaning and feeder values) and press Reset alarm and Reset ignition. Burner ON and OFF are never available from Home Assistant. Every command is checked against the burner's limits and logged.

Anyone who can reach your Home Assistant or MQTT broker can change burner settings while this is on. Use a broker password and TLS.

All values are re-published this often, even when unchanged. Changes are always published immediately.
